💡 设计要点

工具调用式 RAG（非前置检索）

与传统的"先检索再生成"模式不同，这个系统采用 LLM 自主决策是否检索的工具调用模式。Claude 根据问题类型决定：

  • 课程相关问题 → 调用搜索工具 → 基于检索结果回答
  • 通用知识问题 → 直接回答，不浪费检索开销

系统提示词明确限制"每次查询最多一次搜索"，避免多轮工具调用导致延迟过高。

双集合向量存储

ChromaDB 中有两个独立集合：

  • course_catalog — 存储课程标题和元数据，用于模糊匹配课程名（用户说"MCP 课"能找到全名）
  • course_content — 存储分块的课程内容，用于语义搜索

本地嵌入模型

使用 sentence-transformers/all-MiniLM-L6-v2 在本地生成嵌入向量，不依赖外部 API，降低成本且保护数据隐私。
